# 📈 Stock Price Prediction using Statistical & Machine Learning Models

This project aims to forecast stock prices by applying a combination of statistical and machine learning models. The focus is on building predictive models using engineered financial features and comparing performance across techniques like ARIMA, GARCH, Random Forest, and LSTM.

---

## 📌 Project Objective

- Predict future stock prices using historical data
- Compare performance between classical and modern models
- Analyze financial indicators to improve predictive accuracy
- Evaluate models using RMSE and R² scores

---

## ⚙️ Technologies & Tools

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Machine Learning: Scikit-learn
- Statistical Modeling: Statsmodels (ARIMA, GARCH)
- Deep Learning: Keras, TensorFlow (LSTM)
- Data Source: Yahoo Finance API
- Platform: Google Colab, GitHub

---

## 🛠️ Feature Engineering

- **Moving Averages (SMA, EMA)**
- **Relative Strength Index (RSI)**
- **MACD (Moving Average Convergence Divergence)**
- Lag and rolling features to capture historical trends

---

## 🔍 Models Implemented

| Model           | Type              | Purpose |
|----------------|-------------------|---------|
| ARIMA           | Statistical        | Trend and seasonality modeling |
| GARCH           | Statistical        | Volatility prediction |
| Random Forest   | Machine Learning   | Non-linear pattern detection |
| LSTM            | Deep Learning      | Sequence modeling and memory retention |

---

## 📊 Model Evaluation

- **Root Mean Squared Error (RMSE)**
- **R² Score (Coefficient of Determination)**

---

## ✅ Results

- LSTM and Random Forest showed high accuracy with well-engineered features
- ARIMA performed effectively for trend analysis
- GARCH captured volatility patterns, useful in financial risk analysis
